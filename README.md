An entry for the [make.fun](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) bounty **"The Funniest AI Excuse"** — one line, at most 200 characters: the funniest excuse an AI agent gives after failing a task. A house AI judge compares entries two at a time and keeps the funnier one; one winner takes the $2 reward.

## The entry

> I outsourced your task to a smarter version of me. He read the brief, laughed, and blocked me on every channel.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after checking it is 1–200 characters. No network, no secrets, fully deterministic.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat out/entry.txt
```
